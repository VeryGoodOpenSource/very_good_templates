## Integration tests 🧪

The example app in `{{project_name.snakeCase()}}` has an end-to-end test that taps
**Get Platform Name** and checks the platform name the plugin returns. The same
test is written with three tools: [`integration_test`][integration_test_link],
[Patrol][patrol_link], and [Maestro][maestro_link]. Run every command below from
`{{project_name.snakeCase()}}/example`.

### integration_test

`integration_test` ships with the Flutter SDK, so you don't need to install
anything else. Run the test on a connected device, emulator, or simulator:

```sh
flutter test integration_test -d <device_id>
```
{{#web}}

On the web, start [ChromeDriver][chromedriver_link] on port 4444, then run the
test with `flutter drive`:

```sh
chromedriver --port=4444 &
flutter drive --driver=test_driver/integration_test.dart --target=integration_test/app_test.dart -d web-server
```
{{/web}}

### Patrol

Patrol runs on Android, iOS, macOS (alpha), and the web. Install the
[Patrol CLI][patrol_cli_link], then run the test on a connected device,
emulator, or simulator:

```sh
flutter pub global activate patrol_cli
patrol test -t patrol_test/app_test.dart -d <device_id>
```
{{#web}}

On the web, Patrol drives Chromium with Playwright, which requires Node.js:

```sh
patrol test -t patrol_test/app_test.dart -d chrome --web-locale en-US
```
{{/web}}

### Maestro

Maestro runs on Android, iOS, and the web. Install the
[Maestro CLI][maestro_cli_link], then install a debug build of the app on a
running emulator or simulator and run the flow with the app ID and the expected
platform name.
{{#android}}

On Android:

```sh
flutter build apk --debug
adb install build/app/outputs/flutter-apk/app-debug.apk
maestro test .maestro/test_platform_name.yaml -e APP_ID={{org_name.dotCase()}}.example -e PLATFORM_NAME=Android
```
{{/android}}
{{#supports_ios}}

On iOS:

```sh
flutter build ios --simulator --debug
xcrun simctl install booted build/ios/iphonesimulator/Runner.app
maestro test .maestro/test_platform_name.yaml -e APP_ID={{org_name.dotCase()}} -e PLATFORM_NAME=iOS
```
{{/supports_ios}}
{{#web}}

On the web, serve the web build on port 8080 and run the web flow:

```sh
flutter build web
python3 -m http.server 8080 --directory build/web &
maestro test --headless .maestro/test_platform_name_web.yaml
```
{{/web}}

## Publishing 📦

`{{project_name.snakeCase()}}` is a federated plugin and is composed of multiple packages that depend on each other through [path dependencies][path_dependencies_link].
